# Archived original startup observations

These repeated original-executable observations are preserved research evidence.
Byte-identical copies of their cases and observations are registered in the
strict pending replay catalog. They add zero passing candidate cases. The
archive remains immutable source evidence; candidate replay lives separately.

`cases.json` contains synthetic setup/source inputs; `observations.json` preserves
the accepted original output bytes. `original.py` is the exact recorder source.
Only declared input text is changed by the source-control variant; population,
resource stores, starting-unit and roster state are never supplied as answers.
Original executables, installed asset data and process dumps are not included.

To repeat a capture, supply the original assets, private Wine/Xvfb transport and
pinned Windows Python input runtime used by the unit-menu recorder. For v6,
install the archived recorder at
`tools/behavior-tests/ui/natural_first_city_original.py` in an isolated checkout.
For v7, set `SMAC_SOURCE_CHECKOUT` to that checkout and run this archived file.
Use `compare.py record` with these cases and `--repeat 2`; never edit observations
to match a candidate. The recorder fingerprint also covers its versioned imports.

The stock-faction records cover seven first-city setups at Citizen. The source
controls cover only their six named inputs, plus the actual setup-size scalar.
They do not establish an original mineral algorithm, generic startup credit,
mineral-bar semantics, AI, later founding or subsequent turns.
