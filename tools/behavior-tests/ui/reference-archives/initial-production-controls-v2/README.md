# Complete actual first-city production contexts

Each core/source run file preserves complete phase observations from an independent
original pass, with a fresh game per case. The associated strict v2 suite was
recorded twice and accepted. Every native unit roster is preserved at every phase.
Roster fields are excluded from strict comparisons because an earlier full-context
Talent recording differed in unit count. No roster is synthesized or promoted as
deterministic. The exact strict production projection can be checked by removing
only each native phase's `units` field. No other field is projected away.

The phase protocol, isolated source inputs and literal actual-panel measurements
are specified in `../../initial-production-controls-contract.md`. These context
files are optional evidence; neither complete roster determinism nor a general
startup-stock/cost formula is asserted.
