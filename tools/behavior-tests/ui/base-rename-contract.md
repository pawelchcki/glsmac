# Owned-city Rename controls

`ui.base_rename.v1` covers eleven sequences on one declared owned Headquarters in
a fresh Gaian/Citizen/standard flat-arid game. The controlled initial city is
Gaia's Landing, one Doctor, no assigned Workers, zero nutrients and nine minerals;
these are fixture inputs, not natural startup defaults. Scout, Former and Colony
Pod remain stacked, healthy and unspent. Open complete management with Enter
before each trace; no turn is advanced.

Actions click the actual Rename button, focus/edit the real field by clearing
with Backspace and typing declared ASCII text, confirm with Enter or the visible
OK button, cancel with Escape or the visible Cancel button, and close/reopen
management. Cases cover unchanged confirmation, committed and discarded names,
empty input, leading/trailing spaces and a 36-character ASCII input. They do not
prescribe trimming, rejection or truncation answers; only repeated original
observations establish those outcomes.

Each checkpoint observes the native raw city name, citizens and jobs/worked
squares, unit orders/spent movement, selected unit and relative year. City/unit
identity, ownership and positions and the global/owned city membership are
strictly guarded. Complete management checkpoints require the visible resource HUD and
independently read title; map requires the real selected-unit label. The Rename
layer partly covers resources while leaving the actual management title visible. A Rename
checkpoint requires its rendered caption, prompt, field label and both buttons,
plus independently read rendered edit text, never an echoed input or inferred
answer. Display strings and draft text use uppercase/whitespace/apostrophe
normalization; committed native names preserve actual case and spaces. Draft
case, leading/trailing spaces and caret shape are outside the OCR comparison.

Common and expansion `#RENAME` blocks are separate declared installed-data input
profiles. Common-only, expansion-only and both-edited cases compare actual source
precedence for caption, prompt and field label. Buttons retain their installed
default wording. The candidate must consume installed Script/labels data through
production parsers. Synthetic data declarations supply equivalent controlled
inputs without original assets in public CI; they are not reference answers.

Record each entire original case independently twice from fresh state. Bind
immutable outputs to input and observer/source fingerprints. Candidate replay
must execute the actual mounted Rename control, production handlers and native
name storage. Rendering/timer/transport boundaries must be explicit; fixtures
must not set the renamed value, fabricate title refresh or substitute a name
algorithm. Missing controls or failed state guards remain strict errors.
Real browser input checks the event bridge separately.

The original recorder keeps the pointer over each Rename control during both
mouse edges; the initial pause/tutorial preference controls use the same pacing.
A blinking caret can overwrite draft glyphs. Such frames supply no text: the
observer waits for two matching complete clean readings, retaining a prior clean
reading across caret-only frames. Other unreadable frames reset consensus.
Actual identity, ownership or other native context failures remain fatal.

Scope excludes Unicode, arbitrary punctuation/lengths outside the recorded text,
other factions/populations, foreign cities, duplicate-name policies, save/load,
network synchronization, notification history, terrain/economy behavior and full
game parity. Native authority, stale callbacks, rollback/codec and asynchronous
frontend delivery may have separate application regressions, without claiming
original observations for those invariants.

The eleven accepted traces each have two identical independent original captures.
For these inputs, confirmation commits an empty name and preserves surrounding
spaces; the 36-character input is capped at 24 characters in both the visible
draft and native stored name. Cancellation preserves the old name, including
when Rename is reopened. Common Script wording takes precedence when both
RENAME blocks are edited; expansion-only edits leave the common wording in use.
These are bounded observations, not claims about arbitrary text or other dialogs.
