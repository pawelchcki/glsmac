# `ui.large_map_warning.v1`

Inputs describe the random/custom setup route, two canonical decimal strings
typed into the actual custom-size fields (2 through 256), Enter or OK submission,
up to six warning-control actions, and a controlled source-text profile. The
final action may confirm through Enter, Escape or OK. Earlier actions can move
selection or click either option. Every original case starts a fresh process and
reset INI in a private Wine/Xvfb installation of the pinned GOG SMACX 2.0 profile.

The 68 input sequences cover both routes, small and boundary dimensions, odd
vertical values, keyboard selection, Home/End, mouse selection, confirmation and
caller return. Controlled profiles change only VERYLARGEMAP captions and the
last two choice lines in common Script.txt, expansion xscript.txt, or both with
conflicting synthetic text. The original paragraph body and other blocks remain
unchanged. Source validation, case hashes and two independent complete recordings
bind each observation. Failed or incomplete attempts create no reference file.
Ten additive navigation sequences in `large-map-warning-navigation.json`
inspect repeated arrow boundaries and Home/End after the second choice is
selected. They use a separate observation file and leave the first input set
and its evidence unchanged.
Six further cases in `large-map-warning-odd-heights.json` observe a small odd
height without a warning and actual continuation past warnings at odd heights.
All 84 traces are independently repeated; earlier records remain unchanged.

Outputs contain the actual edited field strings before submission and every
subsequent visible screen, with captions, ordered options, current highlight,
confirmation button and setup kind. Text is normalized to uppercase/one-line
whitespace. Numeric strings come from OCR, without expected-digit or input-length
substitution. Initial native value rectangles locate input left edges; the full
remaining field width is inspected. The pinned blue glyphs are isolated and only
contiguous full-height caret columns are removed. Shorter digit strokes remain.
OCR requires agreement at three image scales; complete checkpoints must stabilize.
Warning selection supports the observed focused and unfocused palettes and fails
on unknown colors. The existing verified read-only four-byte setup-kind observer
is reused; process identity and executable mapping checks still apply.

An `available` flag records whether the relevant actual controls exist before an
action. Both initial editing/submission checkpoints require the dimension
controls. Warning actions target the actual warning options, button or window.
If those controls are absent in the candidate, no action is delivered to an
unrelated menu: the adapter records `available: false` and its actual screen.
This remains a strict mismatch against an available original warning control.
Missing, reordered, duplicate, malformed, incomplete and failed worker traces
cannot count as matches.

Candidate replay uses current production menu steps, popup manager, controls,
native Rules/MapSettings and native source parsing. Only display, audio, timer
delivery, equivalent synthetic installed text and the pre-world lifecycle are
controlled. Each fixture has independent native settings; immutable source bundles
are shared within a profile as they are within a menu controller. Actual control
values/classes and native setup kind are observed, rather than inferred from
requested actions. No installed assets or rendering are required for replay.

This contract observes setup behavior. The separate
[generated-grid contract](custom-grid-dimensions-contract.md) establishes selected
coordinate units and odd heights. This warning contract does not establish
normalization during terrain generation, bounds outside the
declared inputs, nonnumeric editing, warning paragraph typography, generated
terrain, save/load or full-game parity. Warning paragraphs are consumed from
installed data and checked separately with synthetic regression inputs, without
redistributing the original paragraph in this evidence.
