# Mandatory interface-tour controls

`ui.interface_tour_controls.v1` follows the declared natural explicit Cybernetic
Tiny/Citizen/standard opening. It clicks the actual Tour control, then either
clicks End Tour on its first page or advances with Enter through Continue and
the final Close. Observations compare the mandatory interface topics, actual
ordered button labels, MENU and Commlink panel visibility, the native turn
counter and preservation of human unit positions, prototype, damage, orders
and movement spent.

The full case projects fifteen mandatory checkpoints; the early dismissal
case has three. Both include the opening Tour/Close prompt. The original observer classifies visible body text against the
installed tutorial data, reads actual rendered controls and panels, and reads
native counters/state without writes. All terrain-dependent pages remain in
private screenshots and traces but are excluded from this declared projection:
the natural random world is not seeded to force an ocean or fungus example.

These installed-asset rendered comparisons remain separate from the asset-free
default UI catalog. Missing candidate controls are explicit incomplete traces
and mismatches. Runtime, graphics and capture failures remain errors.

This is a control-sequence contract. Full paragraph text, font/layout/chrome,
arrow endpoints, keypad geometry, terrain-dependent demonstrations, animation,
camera/fog/world generation and computer-player behavior remain outside it.
It cannot establish full opening-through-first-round or frame-by-frame parity.
