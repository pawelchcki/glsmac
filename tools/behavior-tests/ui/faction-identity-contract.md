# `game.faction_identity.v1`

Each input follows New Game, random map, Tiny, Citizen and standard rules, then
uses the real roster and name/customization editors. The final Enter confirms
the name and generates the original world. Checkpoints require the actual
post-generation opening dialog, located by its rendered title frame, independently
read caption and confirmation button. Cult and Progenitor openings have their
own captions and heights; they are not assumed to say Planetfall.

The output is six strings in editor order: leader name, formal faction name,
noun, adjective, leader title and leader description. These come from the actual
selected human faction's stored identity. A guarded **one-byte** human mask
selects its record; neighboring flags are excluded. Reads require the owned,
pinned executable and writable mapped data. No requested text, source file,
lookup dictionary, code inspection or memory write supplies an answer.
Independent complete original runs must agree before reference evidence is
written. Partial research captures are not reference observations.

The cases exercise all fourteen default factions, confirmed/canceled/restored
six-field customization, final name edits, whitespace, length limits, an empty
name and conflicting common/expansion text profiles. Source changes are inputs.
The source corpus and observer are fingerprinted independently of the observed
outputs. Original text and artwork remain private.

Candidate replay runs current source consumers and actual popup handlers with
mocked display, input delivery, artwork and start lifecycle. The start request
passes through the production native identity validator, storage and wrapper in
an asset-free faction fixture. Its actual returned values form the comparison;
each case also checks native serialization and independent receiving ownership.
Real browser tests separately verify the launcher, selected native faction,
Player name and identity after world generation and playable turns.

This is a textual identity contract. It excludes the editable Gender field's
in-game semantics, the source leader-gender flag, random faction allocation,
the six opponent slots, computer turns, diplomacy, grammatical substitutions
in every dialog, portraits, faction mechanics and full game parity. Existing
seven-field editor coverage does not establish those in-game effects. The native
faction codec gains identity fields; compatibility with older unversioned
snapshots is not established.
