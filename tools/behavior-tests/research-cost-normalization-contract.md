# Additional normalization and ranking witnesses

This separate reference suite contains 19 synthetic input cases
executed by the same pinned original helper. Two independent complete original
runs agree. Eighteen inputs are additional witnesses; one repeats an earlier
input as an anchor. All prior cases and observations remain byte-for-byte
unchanged.

The input schema, initialized fixture defaults and limitations remain those in
[research-cost-contract.md](research-cost-contract.md). Every new input fixes
map-area scalar56, discovery/faction percentages100, difficulty0. The families
are:

| Input family | Controlled values |
| --- | --- |
| Saved earned counter | Every integer0..8, turn1, rating0, ranking0 |
| Saved earned8 and ranking16 | Turns1,8,80 crossed with stagnation off/on; rating0 |
| Research rating | Saved earned4 and8 crossed with ratings-1,+1; turn1, ranking0 |

Exact outputs are independently recorded observations, not values generated by a
candidate or an accompanying formula. Ownership-to-counter mapping, general
map-dimension conversion, nonzero rival counters, acquisition and general
science-credit timing remain unverified.

```sh
python3 tools/behavior-tests/compare.py record \
  --cases tools/behavior-tests/cases/human-research-cost-normalization.json \
  --command '/tmp/glsmac-reference-venv/bin/python tools/behavior-tests/research_cost_original.py --exe /var/home/pawel/reimplementation/smac-wasm/smac-assets/terranx.exe' \
  --output tools/behavior-tests/observations/human-research-cost-normalization.json \
  --repeat 2 --timeout 60
```
